# Bumply — AI Pregnancy Companion (SaaS demo)

Next.js + Postgres (Supabase) app. Moms sign up, get a personalised weekly update
(baby development, 7-day meal plan, partner notes, affirmation) generated by an
OpenAI-compatible LLM, and can chat with Bumply — gated behind a (stubbed) subscription.

## Stack
- **Next.js 16** (App Router, TypeScript) — frontend + server routes
- **Postgres** via the `postgres` driver, isolated in the `preg_companion` schema (self-hosted Supabase / Railway)
- **Auth** — self-contained: bcrypt password hashes + signed-cookie sessions (`jose`)
- **AI** — `openai` SDK pointed at **NVIDIA NIM** (OpenAI-compatible; swap base URL/key/model via env)

## Setup
1. `cp .env.example .env.local` and fill in values (DB URL, NVIDIA key, `AUTH_SECRET` via `openssl rand -hex 32`).
2. `npm install`
3. `npm run db:setup`  — creates tables in the `preg_companion` schema
4. `npm run dev`       — http://localhost:3000

> **Model note:** `meta/llama-3.3-70b-instruct` currently times out on this NVIDIA key (heavy queueing).
> The default is `meta/llama-3.1-8b-instruct` (~1s, valid output). Change `NVIDIA_MODEL` to swap.

## What works
- Landing page (ported from the original design) + signup/login
- **Auto-advancing gestational week** computed from due date; **vetted week-by-week baby facts** (never AI-hallucinated)
- Per-mom dashboard: instant baby hero + progress + full history; **instant signup** (notes generate in the background)
- **Streaming AI chat** grounded in her week, profile, and recent journal — with suggested prompts + safety disclaimer
- **Journal** (`/journal`): daily mood + symptom check-ins that feed the chat
- **Tools** (`/tools`): kick counter (saved) + contraction timer
- Stubbed subscription: `/pricing` "Subscribe" flips to premium (no payment); premium gates meal plans, partner notes, chat
- Weekly page viewer at `/my-update/[slug]` (replaces the old static `update.html` + n8n lookup)
- **Weekly delivery**: `/api/cron/weekly?secret=$CRON_SECRET` generates + emails (SMTP) + WhatsApps (Cloud API) each mom's update — both channels env-gated, skipped cleanly if unset
- **PWA**: installable, offline shell, theme color, manifest
- **Admin panel** at `/admin` (password = `ADMIN_PASSWORD`): user stats, user management (plan/delete), run-weekly-job, and editable settings (price, AI model, send day, feature flags). Settings genuinely drive the app.
